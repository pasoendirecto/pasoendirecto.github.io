Política de privacidad — PasoEnDirecto

Última actualización: 19 de noviembre de 2026

Qué es esta aplicación

«PasoEnDirecto» es una herramienta privada que usa únicamente el propietario del canal de YouTube @PasoEnDirecto para subir y programar vídeos en su propio canal mediante los Servicios de API de YouTube. No está abierta al público ni la usan otras personas.

Uso de los Servicios de API de YouTube

Esta aplicación utiliza los Servicios de API de YouTube. Al usarla, aceptas los Términos del Servicio de YouTube. Consulta también la Política de Privacidad de Google.

Qué datos se usan

  • Se solicita acceso a la cuenta de YouTube del propietario solo para subir vídeos y leer el identificador del canal, y así comprobar que se publica en el canal correcto.
  • El token de acceso se guarda solo en el ordenador del propietario. No se envía a ningún servidor de terceros.
  • No se recogen, venden ni comparten datos personales de ningún usuario o espectador.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento en la página de permisos de la cuenta de Google: security.google.com/settings/security/permissions. Al revocarlo, la aplicación deja de tener acceso y se puede borrar el token guardado en el ordenador.
